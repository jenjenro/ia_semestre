Explicacion Linea a Linea del Dashboard (Frontend)

El dashboard se compone de dos archivos principales en la carpeta dashboard/: index.html y app.js.

1. index.html (Estructura y Estilos visuales)

  • Tailwind CSS: En la seccion <head> cargamos Tailwind via CDN. Esto nos permite disenar botones, paneles y sombras directamente usando clases en el HTML (como bg-indigo-600 o rounded-lg) sin escribir un archivo de estilos CSS separado.
  • FontAwesome: Tambien se carga en el <head> para utilizar iconos como el de la papelera (fas fa-trash) o la lupa.
  • Estructura de Columnas: La pagina se divide en dos grandes columnas:
    • Panel Izquierdo: Contiene el formulario principal (<form id="uploadForm">) donde el usuario selecciona un archivo. Tambien muestra los estados de "Cargando..." y la seccion de resultados.
    • Panel Derecho: Muestra el panel del Historial, el boton de actualizar y el boton de vaciar historial.
  • Modal de Imagenes: Al final del documento hay un contenedor oculto (div id="imageModal") que sirve para mostrar las imagenes procesadas en pantalla completa cuando el usuario hace clic en ellas.

2. app.js (Logica e Interactividad)

Este archivo es el corazon del frontend y se encarga de comunicarse con el servidor Python (FastAPI).

  • const API_BASE = (window.location.port === '8000') ? '' : `http://${window.location.hostname || 'localhost'}:8000`;
    Configuracion de Red: Esta linea calcula automaticamente la direccion del servidor. Si estas usando VS Code Live Server (puerto 5500), deduce que el backend esta corriendo en el puerto 8000 de tu maquina para evitar errores de red (Failed to fetch) o problemas de CORS.
  • const uploadForm = document.getElementById('uploadForm');
    Captura de Elementos: Se declaran variables para controlar cada pedazo del HTML desde Javascript.
  • uploadForm.addEventListener('submit', async (e) => { ... })
    Subida de Archivos: Cuando se presiona "Procesar", se detiene la recarga de la pagina con e.preventDefault(). Se arma un paquete (FormData) con el archivo seleccionado y se hace un fetch() a la ruta /api/upload del servidor.
  • function renderImageResults(data) / renderTextResults(data)
    Renderizado Dinamico: Dependiendo del tipo de archivo (Texto o Imagen), se genera el HTML para mostrar la clasificacion, el nivel de confianza y la explicacion de que caracteristicas tomo la IA. Todo este HTML se inserta dentro del contenedor resultsContent.
  • async function loadHistory() { ... }
    Carga del Historial: Hace una peticion GET a /api/history. Recorre cada elemento de la base de datos y pinta una tarjeta con el nombre del documento y su categoria. Le anade onclick="handleHistoryClick(this)" para que sean clickeables.
  • window.handleHistoryClick = function(element) { ... }
    Visualizar Historial: Cuando haces clic en un elemento del panel derecho, esta funcion extrae los datos JSON guardados en esa tarjeta y los renderiza en la vista principal usando la funcion renderHistoryResult(item).
  • clearHistoryBtn.addEventListener('click', ...)
    Borrar Todo: Al confirmar, envia una peticion DELETE /api/history que le avisa a Python y SQLite que borren la base de datos completa.
  • window.deleteHistoryItem = async function(e, id) { ... }
    Borrado Individual: Manda un DELETE /api/history/{id} para borrar especificamente ese archivo. e.stopPropagation() evita que al hacer clic en la papelera se abra el documento por error.
